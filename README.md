# lee-x-analysis

이재명 대통령 X 계정([@Jaemyung_Lee](https://x.com/Jaemyung_Lee))의 게시 활동을 수집·분석한 자료와 코드입니다.
2021년 8월부터 2026년 9월까지 62개월, 2,427건의 월별 집계와, 취임 이후 14개월(2025-07 ~ 2026-09) 799건의 주제 군집 분석을 담고 있습니다.

**결과 보기**

- [월별 게시 빈도 (5년)](https://leejeonghwan.github.io/lee-x-analysis/) — 62개월 추이와 정치 일정
- [메시지 지도](https://leejeonghwan.github.io/lee-x-analysis/map.html) — 799건을 문장 임베딩으로 2차원에 펼친 주제 지도

---

## 왜 만들었나

한국일보가 "6월 78건, 7월 81건이었는데 8월 들어 27일까지 31건"이라고 보도했습니다.
숫자 자체는 대체로 맞았지만 두 가지가 확인되지 않은 채였습니다.

1. 그 숫자가 무엇을 세고 무엇을 뺀 것인지 — 리트윗, 인용, 답글, 스레드 처리에 따라 4~5%가 흔들립니다.
2. **무엇이** 줄었는지 — 총량만으로는 알 수 없습니다.

이 저장소는 두 질문에 답하기 위한 원자료와 절차입니다.

## 무엇이 나왔나

### 8월 급감의 절반은 순방의 부재

외교 성격의 세 군집(다자외교·영문 성명·순방 현장)이 **7월 33건에서 8월 7건**으로 줄었습니다.
7월은 NATO(튀르키예)–몽골–샌프란시스코–브라질–칠레–아르헨티나로 이어진 연쇄 순방의 달이었고,
8월 2~3일 프랑크푸르트를 끝으로 순방이 끊깁니다. "이번 정류장은 ○○입니다" 류의 이동 실황이 통째로 사라집니다.

### 그런데 국내 메시지도 같이 줄었다

외교를 뺀 나머지가 7월 50건 → 8월 30건, 일평균 1.61 → 0.97건.
순방만으로는 설명되지 않는 감소가 남습니다.

### 9월에 반등했다

9월 1~8일 24건, 일평균 3.0건으로 6~7월(2.67·2.71)을 넘어섰습니다.
프랑스 뤼미에르 서밋 순방이 재개되며 외교 군집이 돌아왔습니다.
8월의 골짜기는 추세 변화라기보다 일정의 공백에 가까워 보입니다.

### 그 밖에

- **부동산·세제 군집이 2026년 1~2월에 37건으로 몰려 있습니다.** 종부세·양도세 쟁점을 대통령이 직접 길게 설명하는 글들이고, 정책 국면과 동기화됩니다.
- **가장 큰 군집은 의례입니다.** 추모·축하·격려·재외동포 인사가 173건, 전체의 22%. 계정의 바닥을 받치는 층이고 8월에도 상대적으로 덜 줄었습니다.
- **2021년 9월 200건은 개인의 다작이 아니라 캠프 계정이었기 때문입니다.** 그달 본문을 읽어보면 지역별 경선 투표 독려 39건, 캠프 일정 안내·알람봇 35건이고, 200건 중 69건 끝에 `- 이재명 후원회 -` 푸터가 자동으로 붙어 있습니다. 9월 8일 글은 아예 `[열린캠프에서 답변 드립니다.]`로 시작합니다.

**따라서 월별 그래프의 봉우리(2021-08~2022-03, 2025-04~05)는 캠프가 굴린 숫자이고, 취임 이후 구간은 성격이 다른 숫자입니다.** 같은 축에 놓고 "예전엔 활발했는데 요즘 줄었다"고 말하면 사과와 오렌지를 비교하게 됩니다. 취임 이후 구간끼리의 비교는 운영 주체가 일정하므로 그대로 유효합니다.

## 데이터

X 이용약관은 게시물 본문의 대량 재배포를 제한하고 게시물 ID 공유를 권장합니다.
이 저장소는 **ID와 파생 지표만** 공개합니다. 본문은 포함하지 않으며, `collect/` 스크립트로 재수집할 수 있습니다.

| 파일 | 내용 |
|---|---|
| `data/monthly_counts.csv` | 62개월 월별 게시물 수 (`month, posts, replies, active_days`) |
| `data/posts.csv` | 취임 후 799건의 ID·시각·군집·t-SNE 좌표·좋아요 수·원문 링크 |
| `data/clusters.csv` | 8개 군집의 라벨, 규모, 특징어 |
| `data/monthly_composition.csv` | 월별 × 군집별 건수 |

`posts.csv` 컬럼:

```
tweet_id       게시물 ID (문자열로 읽을 것 — 19자리라 정수로 읽으면 정밀도가 깨집니다)
datetime_kst   작성 시각, 한국시간
cluster        군집 번호 0~7
cluster_label  군집 이름
tsne_x, tsne_y 2차원 투영 좌표
likes          좋아요 수 (수집 시점 기준)
is_reply       답글 여부
is_quote       인용 여부
url            원문 링크
```

## 방법

### 수집 — `collect/collect_x.js`

X 검색 API(`SearchTimeline`)를 월 단위로 쪼개 커서 페이지네이션으로 전수 수집합니다.
프로필 타임라인(`UserTweets`)은 약 870건에서 페이지네이션이 끊겨 5년치를 못 내려가므로 검색으로 우회했습니다.

`SearchTimeline` 요청에는 `x-client-transaction-id` 헤더가 필요한데 이 값은 웹 클라이언트가
난독화된 코드로 매 요청마다 새로 만들고 재사용이 되지 않습니다. 그래서 헤더를 위조하는 대신
**웹 클라이언트가 스스로 만든 요청의 URL을 가로채 바꾸는** 방식을 씁니다
(`XMLHttpRequest.prototype.open` 후킹). 로그인한 브라우저 콘솔에서 실행합니다.

- 포함: 원글, 인용, 답글
- 제외: 리트윗 (X 검색이 반환하지 않습니다)
- 월 경계는 한국시간(UTC+9)으로 다시 묶습니다
- 검색 API는 15분당 50건 제한이 있어 429를 만나면 대기합니다

### 분석 — `analyze.py`

1. URL·멘션·후원회 푸터를 제거하고 본문을 정규화
2. [`minishlab/potion-multilingual-128M`](https://huggingface.co/minishlab/potion-multilingual-128M) 정적 임베딩으로 벡터화 (torch 불필요)
3. PCA 50차원 → t-SNE 2차원 (cosine)
4. k-means(k=8) 군집, 클래스별 TF-IDF로 특징어 추출

```bash
pip install model2vec scikit-learn numpy
python analyze.py          # posts_full.json 을 읽어 points.json 을 씁니다
```

## 한계

- **삭제된 게시물은 잡히지 않습니다.** 과거 달의 수치는 원칙적으로 하한선입니다.
- **리트윗이 빠져 있습니다.** 프로필 타임라인과 교차 검증한 결과 최근 12개월은 리트윗을 뺀 값과 거의 정확히 일치했습니다(최대 오차 1건).
- **군집은 k-means 강제 분할입니다.** 경계가 깔끔하지 않고, 특히 '개혁·반론·정치'(141건)는 여러 성격이 섞여 있습니다. 지도에서 회색으로 흩어진 점들은 어느 군집에도 잘 붙지 않는 글들입니다.
- **2026년 9월은 8일까지의 부분 집계입니다.** 다른 달과 직접 비교하지 마십시오.
- 군집 라벨은 특징어와 표본을 읽고 사람이 붙인 것입니다. 자동 생성이 아닙니다.
