# lee-x-analysis

이재명 대통령 X 계정([@Jaemyung_Lee](https://x.com/Jaemyung_Lee))의 게시 활동을 수집·분석한 자료와 코드입니다.
2021년 8월부터 2026년 10월까지 63개월, 2,724건의 월별 집계와, 취임 이후 17개월(2025-06 ~ 2026-10) 1,156건의 주제 군집 분석을 담고 있습니다.

**결과 보기**

- [월별 게시 빈도 (5년)](https://leejeonghwan.github.io/lee-x-analysis/) — 63개월 추이와 정치 일정
- [메시지 지도](https://leejeonghwan.github.io/lee-x-analysis/map.html) — 924건을 문장 임베딩으로 2차원에 펼친 주제 지도
- [메시지 지도 (임베드용)](https://leejeonghwan.github.io/lee-x-analysis/embed.html) — 기사에 붙이는 용도

새 달이 지난 뒤의 갱신 절차는 [UPDATE.md](UPDATE.md) 에 있습니다. 명령 하나입니다.

## 기사에 붙이기

지도만 떼어낸 `embed.html`을 iframe으로 붙입니다. 워드프레스라면 '사용자 정의 HTML' 블록에 그대로 넣으면 됩니다.

```html
<iframe src="https://leejeonghwan.github.io/lee-x-analysis/embed.html"
        title="이재명(대통령) X 게시물 분석"
        width="100%" height="720" loading="lazy"
        style="border:1px solid #e3e2dd;border-radius:8px;max-width:100%"></iframe>
```

모바일에서는 내용이 짧아지므로 높이를 줄이고 싶다면 아래를 함께 넣습니다.
임베드가 자기 높이를 `postMessage`로 알려주므로 부모 페이지가 받아서 맞춥니다.

```html
<script>
window.addEventListener('message', function (e) {
  if (!e.data || e.data.type !== 'lee-x-embed:height') return;
  document.querySelectorAll('iframe[src*="lee-x-analysis/embed.html"]')
    .forEach(function (f) { f.style.height = e.data.height + 'px'; });
});
</script>
```

**옵션** — 쿼리스트링으로 조절합니다.

| 파라미터 | 값 | 설명 |
|---|---|---|
| `theme` | `light` / `dark` | 지정하지 않으면 독자의 기기 설정을 따릅니다 |
| `clusters` | 군집 번호, 쉼표로 구분 (개수 제한 없음) | 처음부터 켤 주제. 기본값은 아홉 개 전부 |

```
embed.html?theme=light&clusters=2,8
```

군집 번호는 `data/clusters.csv`에 있습니다. 아홉 개를 한꺼번에 켜도 되고,
각 군집은 고정된 색을 씁니다. 색은 색각 이상(적록·청황) 시뮬레이션으로
인접 쌍 분리도를 검증한 9색 조합입니다. 넷 이하를 켜면 지도 위에 군집 이름이
직접 찍히고, 그보다 많으면 라벨이 겹치므로 위쪽 칩이 범례 역할을 합니다.

## 왜 만들었나

한국일보가 "6월 78건, 7월 81건이었는데 8월 들어 27일까지 31건"이라고 보도했습니다.
숫자 자체는 대체로 맞았지만 두 가지가 확인되지 않은 채였습니다.

1. 그 숫자가 무엇을 세고 무엇을 뺀 것인지 — 리트윗, 인용, 답글, 스레드 처리에 따라 4~5%가 흔들립니다.
2. **무엇이** 줄었는지 — 총량만으로는 알 수 없습니다.

이 저장소는 두 질문에 답하기 위한 원자료와 절차입니다.

## 무엇이 나왔나

### 2026년 1월, 계정의 성격이 바뀌었다

세 지표가 같은 달에 함께 꺾입니다.

| | 2025-12 | 2026-01 |
|---|---|---|
| 사진·동영상이 붙은 글 | 78.3% | **33.3%** |
| 기사 링크를 건 글 | 17.4% | **59.1%** |
| 반론·논쟁 군집 | 6.5% | **18.2%** |

현장 사진을 올리던 계정이 남의 기사를 끌어와 반박하는 계정으로 옮겨갔습니다.
그리고 되돌아오지 않았습니다. 취임 후 첫 일곱 달(2025년 6~12월) 반론·논쟁은
2.6%였고, 2026년 1월 이후 열 달은 **23.0%**입니다. 최고는 5월 37.3%,
가장 낮은 7월도 10.7%로 예전 수준으로 내려간 적이 없습니다.

### 인용하는 기사는 다음이 네이버의 두 배다

외부 링크 284건 가운데 다음 161건, 네이버 83건입니다. 반론·논쟁 군집만
떼어 보면 쏠림이 더 심해서, 그 군집이 건 링크 89건 중 **69건이 다음**입니다.
네이버 쪽은 짧은 주소(`naver.me`)가 섞여 있어 셈법에 따라 비율이 달라집니다.
`naver.me`를 빼면 161 대 33이 됩니다.

### 주제마다 매체가 다르다

| 군집 | 건수 | 기사 링크를 건 글 | 유튜브 링크 |
|---|---|---|---|
| 부동산·세제 | 93 | **64.5%** | 0 |
| 반론·논쟁 | 204 | 43.6% | 1 |
| 치안·민생 단속 | 135 | 28.9% | 14 |
| 순방 현장 | 97 | 2.1% | **78** |
| 영문 외교 성명 | 134 | **0%** | 0 |

정책을 설명할 때는 남의 기사를 끌어오고, 외교를 말할 때는 자기 문장만 씁니다.
순방은 영상으로 보여주고, 영문 성명은 링크 없는 본문입니다.

### 10월은 취임 후 가장 많이 쓴 달이다

29일까지 155건, 일평균 5.34건으로 9월(126건)을 이미 넘어섰습니다.
그중 반론·논쟁이 42건입니다.

### 8월의 골짜기는 추세가 아니었다

일평균이 7월 2.71건 → **8월 1.19건** → 9월 4.20건으로 움직였습니다.
8월 급감의 절반은 순방의 공백이었습니다. 외교 두 군집(영문 외교 성명·순방 현장)이
7월 32건에서 8월 3건으로 줄었습니다. 7월은 NATO(튀르키예)–몽골–샌프란시스코–브라질–칠레–아르헨티나로
이어진 연쇄 순방의 달이었고, 8월 2~3일 프랑크푸르트를 끝으로 순방이 끊겼습니다.

### 그 밖에

- **2021년 9월 200건은 개인의 다작이 아니라 캠프 계정이었기 때문입니다.** 그달 본문을 읽어보면 지역별 경선 투표 독려 39건, 캠프 일정 안내·알람봇 35건이고, 200건 중 69건 끝에 `- 이재명 후원회 -` 푸터가 자동으로 붙어 있습니다. 9월 8일 글은 아예 `[열린캠프에서 답변 드립니다.]`로 시작합니다.

**따라서 월별 그래프의 봉우리(2021-08~2022-03, 2025-04~05)는 캠프가 굴린 숫자이고, 취임 이후 구간은 성격이 다른 숫자입니다.** 같은 축에 놓고 "예전엔 활발했는데 요즘 줄었다"고 말하면 사과와 오렌지를 비교하게 됩니다. 취임 이후 구간끼리의 비교는 운영 주체가 일정하므로 그대로 유효합니다.

## 데이터

X 이용약관은 게시물 본문의 대량 재배포를 제한하고 게시물 ID 공유를 권장합니다.
`data/` 폴더의 CSV는 **ID와 파생 지표만** 담습니다. 본문은 없습니다.

다만 지도 페이지(`docs/`)에는 마우스오버로 보여주기 위한 **본문 앞 200자 발췌**가 들어 있습니다.
전문이 아니라 검색 결과의 미리보기에 해당하는 분량이고, 전체 본문은 `collect/` 스크립트로 재수집해야 합니다.
발췌마저 빼려면 `docs/*.html` 안의 JSON에서 `t` 필드를 지우면 되고, 그 경우 마우스오버에는 날짜·주제·좋아요 수만 남습니다.

| 파일 | 내용 |
|---|---|
| `data/monthly_counts.csv` | 63개월 월별 게시물 수 (`month, posts, replies, active_days`) |
| `data/posts.csv` | 취임 후 1,156건의 ID·시각·군집·t-SNE 좌표·좋아요 수·원문 링크 (본문 없음) |
| `data/clusters.csv` | 9개 군집의 라벨, 규모, 특징어 |
| `data/monthly_composition.csv` | 월별 × 군집별 건수 |
| `data/links.csv` | 게시물별 링크 — 종류·도메인·원래 주소 |
| `data/link_domains.csv` | 외부 도메인별 링크 수 |
| `data/monthly_links.csv` | 월별 링크·미디어 집계 |

`posts.csv` 컬럼:

```
tweet_id       게시물 ID (문자열로 읽을 것 — 19자리라 정수로 읽으면 정밀도가 깨집니다)
datetime_kst   작성 시각, 한국시간
cluster        군집 번호 0~7
cluster_label  군집 이름
tsne_x, tsne_y 2차원 투영 좌표
likes          좋아요 수 (수집 시점 기준)
is_reply       답글 여부
is_quote       인용 여부
url            원문 링크
```

## 방법

### 수집 — `collect/collect_x.js`

X 검색 API(`SearchTimeline`)를 월 단위로 쪼개 커서 페이지네이션으로 전수 수집합니다.
프로필 타임라인(`UserTweets`)은 약 870건에서 페이지네이션이 끊겨 5년치를 못 내려가므로 검색으로 우회했습니다.

`SearchTimeline` 요청에는 `x-client-transaction-id` 헤더가 필요한데 이 값은 웹 클라이언트가
난독화된 코드로 매 요청마다 새로 만들고 재사용이 되지 않습니다. 그래서 헤더를 위조하는 대신
**웹 클라이언트가 스스로 만든 요청의 URL을 가로채 바꾸는** 방식을 씁니다
(`XMLHttpRequest.prototype.open` 후킹). 로그인한 브라우저 콘솔에서 실행합니다.

- 포함: 원글, 인용, 답글
- 제외: 리트윗 (X 검색이 반환하지 않습니다 — 리트윗 추이를 보려면 `UserTweets` 나 공식 API로 수집 경로를 바꿔야 합니다)
- 링크는 `t.co` 로 단축돼 있어 `entities.urls[].expanded_url` 에서 원래 주소를 꺼내 저장합니다
- 월 경계는 한국시간(UTC+9)으로 다시 묶습니다
- 검색 API는 15분당 50건 제한이 있어 429를 만나면 대기합니다

### 분석 — `refit.py`

1. URL·멘션·후원회 푸터를 제거하고 본문을 정규화
2. [`minishlab/potion-multilingual-128M`](https://huggingface.co/minishlab/potion-multilingual-128M) 정적 임베딩으로 벡터화 (torch 불필요)
3. PCA 50차원 → t-SNE 2차원 (cosine)
4. k-means(k=10) 군집. 7건짜리 전산장애 군집은 성격이 가까운 치안·민생 단속에 합쳐 9개로 정리했다. 클래스별 TF-IDF로 특징어 추출

```bash
pip install model2vec scikit-learn numpy
python3 refit.py --k 10     # 처음부터 다시 적합한다
```

### 갱신 — `update.py`

```bash
python3 update.py --add ~/Downloads/posts_2611.json
```

한 번 돌리면 지도를 새로 적합하고 `docs/` 와 `data/` 전체를 다시 씁니다.
좌표는 움직입니다. 새 글이 들어오면 지형도 달라지는 게 맞습니다. 대신 두
가지를 붙들어 둡니다.

- **군집 정체성** — k-means 를 예전 중심에서 출발시킵니다(warm start). 군집 6 은
  다음 달에도 '치안·민생 단속'입니다. 손으로 붙인 이름, 9색 팔레트, 임베드의
  `clusters=` 파라미터가 그대로 맞습니다. 찬 상태로 다시 적합하면 번호가 임의로
  뒤바뀌어 매달 이름을 다시 붙여야 합니다.
- **방향** — t-SNE 는 회전과 반사를 임의로 정하므로, 겹치는 글들을 기준으로
  예전 지도에 맞춰 돌려 놓습니다(프로크루스테스).

매 실행마다 예전 라벨 유지율과 '겹치는 글이 움직인 거리'를 보고합니다.
데이터가 같으면 결과도 같습니다(움직인 거리 0.00).

좌표를 아예 고정해야 할 때 — 기사에 임베드를 붙여 놓고 캡처와 어긋나면 안 되는
동안 — 는 `--freeze` 를 씁니다. 절차와 근거는 [UPDATE.md](UPDATE.md),
`--freeze` 근사의 정확도는 `validate_projection.py` 를 보십시오.

## 한계

- **삭제된 게시물은 잡히지 않습니다.** 과거 달의 수치는 원칙적으로 하한선입니다.
- **리트윗이 빠져 있습니다.** 프로필 타임라인과 교차 검증한 결과 최근 12개월은 리트윗을 뺀 값과 거의 정확히 일치했습니다(최대 오차 1건).
- **군집은 k-means 강제 분할입니다.** 경계가 깔끔하지 않고, 특히 '반론·논쟁'(163건)과 '인사·동포·의례'(124건)는 경계가 겹칩니다. 지도에서 회색으로 흩어진 점들은 어느 군집에도 잘 붙지 않는 글들입니다.
- **2026년 10월은 29일까지의 부분 집계입니다.** 다른 달과 직접 비교하지 마십시오.
- 군집 라벨은 특징어와 표본을 읽고 사람이 붙인 것입니다. 자동 생성이 아닙니다.
- **데이터가 갱신되면 좌표가 움직입니다.** t-SNE 는 데이터가 조금 달라져도 다른 국소해로 갑니다. 군집 번호와 이름, 큰 덩어리의 배치는 유지되지만 그 안에서 점들이 섞입니다. 기사에 지도를 실을 때는 "2026년 10월 기준"처럼 시점을 적어 두는 편이 안전합니다. 점 하나의 정확한 위치는 읽는 대상이 아닙니다.
- **2021-08 ~ 2025-06 구간은 집계만 남아 있습니다**(`monthly_hist.csv`). 당시 수집한 원자료 파일을 보관하지 않아서인데, 필요하면 `collect/collect_x.js` 로 그 구간을 다시 수집해 복원할 수 있습니다.
